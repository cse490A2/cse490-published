# CSE 490 A2: Vibe Coding, Autumn 2026

Published course materials. Every file here is a frozen export of a finished document from the course's Google Drive, where the material is written. Canvas links here, and the course website reads from here. Nothing is edited by hand: a change is made in the source document and republished.

| Path | What it is |
|---|---|
| `syllabus.md` | The syllabus. |
| `lectures/LNN/slides.pdf` | The week's lecture slides. |
| `projects/PNN/README.md` | The project handout. Open the folder and GitHub shows it. |
| `projects/PNN/SETUP.md` | Prerequisites and tool setup for that project. |
| `projects/PNN/SUBMISSION.md` | What to turn in, with the template when there is one. |
| `projects/PNN/starter/` | Files a student starts from, byte for byte. `starter.zip` is the same set as one download. |
| `projects/PNN/examples/` | Filled-in samples the handout links to. An `.html` example opens rendered at `https://cse490a2.github.io/cse490-published/...`. |
| `projects/PNN/images/` | Screenshots the handout and setup guide embed. |
| `PUBLISHED.json` | Where each file came from and when it was published. |

Every project folder has the same slots. A slot the week does not use is simply absent.

A project whose work *is* a repository (P03, P05) has its own template repository in this organization instead of a `starter/` folder, so GitHub Classroom can hand each student a private copy. The handout says which kind the week uses.
