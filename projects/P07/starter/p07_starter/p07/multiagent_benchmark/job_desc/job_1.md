Answer every question in questions.md. Every answer comes from the pages served at http://localhost:8765/ (the page server is already running in another terminal; the index at / lists the pages, and fetch_url reads one page). Write the answers as JSON lines to the answers file named in your prompt, one line per question: {"n": <question number>, "answer": "<the answer>", "page": "<the page's filename>"}. Two questions have parts and need several pages; questions.md gives the shape of their line. The run stops when its time limit is reached, helpers included (max_minutes in settings.json), so start the helpers at once. You cannot write files yourself: a helper writes the answers file.
