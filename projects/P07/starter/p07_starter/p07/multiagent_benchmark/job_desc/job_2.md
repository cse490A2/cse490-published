Answer every question in questions.md. Every answer comes from the pages served at http://localhost:8765/ (the page server is already running in another terminal; the index at / lists the pages, and fetch_url reads one page). Write the answers as JSON lines to the answers file named in your prompt, one line per question: {"n": <question number>, "answer": "<the answer>", "page": "<the page's filename>"}. The run stops five minutes after your prompt, helpers included (max_minutes in settings.json), so start the helpers at once. You cannot write files yourself: a helper writes the answers file.

How the team works on this job:
- Read the index first. Split the pages by the kind of record, never by count: one helper owns the deploys and people pages, one the metrics and finance pages, one the support tickets, one the public and after pages, one the database log with the background pages, and three share the booking log, each a run of its pages in order. Start all eight in one call.
- A task is short: the helper's name, its pages, and its answers file. Every helper reads questions.md itself, so the questions are never copied into a task. It reads only its own pages. It answers the questions its pages settle, and for every other question it reports the facts its pages hold that the question needs: a time, a name, a number, with the page.
- A helper on a log reports the first and the last line that did not complete on its pages, copied whole, and the error each names.
- A helper that settles a fact also keeps it with the remember tool, one line: the fact and the page.
- Each helper writes only its own file, answers-<its name>.jsonl. Nobody else writes that file.
- Some questions build on others, so there are two rounds. Round two starts when round one reports: one helper works out every question that needs another's answer, and the summary, from the facts in the reports, which the manager copies into its task word for word, and merges all the files into the answers file. A time in local time is turned into UTC before it is compared.
- Done when every question has exactly one line in the answers file, with the word unknown as the answer where the team could not settle it.
