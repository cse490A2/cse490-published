# artifacts

Save what the models produce here, one file per model, named

    <Game>_<model>.html

The game name first, one underscore, then the model's short name: the part
after `external/` in the model picker. Examples:

    BreakoutDoubles_haiku-4-5-20251001.html
    BreakoutDoubles_kimi-k3.html
    BreakoutDoubles_deepseek.v3.2.html

A game from your own spec takes its own name in the first part. The turn-in
command checks these names before it packages the folder.
