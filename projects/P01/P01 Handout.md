# Project 1: Prompt to Web App

Create a mobile web app using Lovable or Purple (UW). Choose one route below. Set up first: [Setup](Setup.md).

## Lovable

**Due: Tuesday 11:59 pm**

Prerequisites: Create a Lovable account, then use the given code to upgrade to Pro. Steps: [P01: Setup](Setup.md).

You have 40 minutes. Use [Lovable](https://lovable.dev) and come up with a cool mobile phone web app. Ask Lovable if you need ideas. Iterate until it does what you want. Use the annotation tool at least once: in the preview toolbar, select the part you want changed, or draw on it, and describe the change.

If you'd rather keep your work inside UW, use the Purple UW section of this handout instead.

A few examples:

<https://sensory-synth.lovable.app>

### Turnin

By Tuesday 11:59 pm, on the Project 1 assignment in Canvas:

- Publish your app through Lovable and submit the published link.
- Submit a shared link to your Lovable project, so we can read your prompts.
- Attach at least one screenshot of you using the annotation tool.
- Submit as Text: paste both links, then insert your screenshot with the image button.

## Purple UW

**Due: Tuesday 11:59 pm**

Prerequisites: Sign into UW Purple using your UW credentials. Steps: [P01: Setup](Setup.md).

You have 40 minutes. Use UW Purple and come up with a cool mobile phone web app. It runs inside UW, so your prompts and your app stay private. Ask Purple if you need ideas. Iterate until it does what you want. Annotate at least once: screenshot the region you want changed and send it to Purple with the change you want.

If you'd rather have the app published for you, use the Lovable tab of this handout instead.

### Turnin

By Tuesday 11:59 pm, on the Project 1 assignment in Canvas:

- Upload the html file Purple wrote.
- A text file with your prompts, in order.
- Attach the screenshots you sent Purple.
- Submit as Upload: the html file, the prompts file, and the screenshots together, in one submission.
