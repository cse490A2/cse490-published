# Lovable

Assignment: Create a mobile web app using Lovable or Purple (UW). Choose one:  
Project 01: Prompt to Web App  
**Due: Tuesday 11:59 pm**

Prerequisites: Create a Lovable account, then use the given code to upgrade to Pro.

You have 40 minutes. Use [Lovable](https://lovable.dev) and come up with a cool mobile phone web app. Ask Lovable if you need ideas. Start in Chat mode. Tell Lovable your idea and have it ask you questions and draft a plan before you let it build. Your first build prompt is your specification. Iterate until it does what you want. You'll turn in every prompt you send, in order, so keep the chat. Use the annotation tool at least once: in the preview toolbar, select the part you want changed, or draw on it, and describe the change.  
If you'd rather keep your work inside UW, use the Purple tab of this handout instead.

A few examples:  
[https://sensory-synth.lovable.app](https://sensory-synth.lovable.app)  
[https://fairy-chat-coach.lovable.app](https://fairy-chat-coach.lovable.app)

## Turnin

By Tuesday 11:59 pm, on the Project 1 assignment in Canvas:

- Publish your app through Lovable and submit the published link.  
- Paste your prompts, in order. Scroll to the top of the Lovable chat and copy each message you sent; your first build prompt is your specification.  
- Attach at least one screenshot of you using the annotation tool.  
- Submit as Text: paste the published link and your prompts, then insert your screenshot with the image button.

# Purple

Project 01: Prompt to Web App  
**Due: Tuesday 11:59 pm**

Prerequisites: Sign into UW Purple using your UW credentials. 

You have 40 minutes. Use UW Purple and come up with a cool mobile phone web app. It runs inside UW, so your prompts and your app stay private. Ask Purple if you need ideas. Purple has no plan mode, so make one. Before you ask for code, ask Purple to draft a plan and to ask you questions about what you want. Then tell it to build. Iterate until it does what you want. You'll turn in every prompt you send, in order, so keep the chat. Annotate at least once: screenshot the region you want changed and send it to Purple with the change you want.   
If you'd rather have the app published for you, use the Lovable tab of this handout instead.

## Turnin

By Tuesday 11:59 pm, on the Project 1 assignment in Canvas:

- Upload the html file Purple wrote.  
- A text file with your prompts, in order: copy each message you sent from the Purple chat.  
- Attach the screenshots you sent Purple.  
- Submit as Upload: the html file, the prompts file, and the screenshots together, in one submission.
