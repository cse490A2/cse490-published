# Shopping list

This is a subskill. It lives at `skills/meal-plan/shopping-list/SKILL.md`
and is loaded only when the parent skill's text names it, so the parent
stays short.

1. Take the final plan from this session. Do not re-plan.
2. List every ingredient for every dish, with the amount for one person.
3. Remove what `memory.md` says is always in the kitchen: oil, salt,
   pepper, rice, pasta, onions, garlic.
4. Group the rest by where it sits in a store: produce, meat and fish,
   dairy, dry goods, frozen.
5. Show the list. Ask whether anything is already at home, and remove it.
